# Настройка VK-бота для развёртывания

## 1. Создание группы ВКонтакте

1. Зайти на https://vk.com/groups → «Создать сообщество»
2. Выбрать тип: **Бизнес** или **Бренд или организация**
3. Назвать группу (например: «СУУПР Бот»)
4. Перейти в **Управление → Настройки → Работа с API**

## 2. Получение токена сообщества

1. **Управление** → **Настройки** → **Работа с API** → **Ключи доступа**
2. Нажать «Создать ключ»
3. Отметить галочки:
   - ✅ Разрешить приложению управлять сообществом
   - ✅ Разрешить приложению отправлять сообщения от имени сообщества
   - ✅ Разрешить доступ к фотографиям сообщества
4. Скопировать ключ — это `VK_BOT_TOKEN`

## 3. Включение сообщений и Long Poll

1. **Управление** → **Сообщения** → Включить «Сообщения сообщества»
2. **Управление** → **Настройки** → **Работа с API** → **Long Poll API**
   - Включить Long Poll API
   - Версия API: **5.199** (или последняя доступная)
   - Типы событий: отметить все в разделе «Сообщения»

## 4. Получение ID группы

- ID группы виден в URL: `https://vk.com/club<ID>` → цифры после `club`
- Или: **Управление** → **Настройки** → справа будет указан ID
- Это `VK_GROUP_ID`

## 5. Настройка на сервере

Подключиться к серверу по SSH и отредактировать `local.env`:

```bash
ssh root@186.246.10.51
nano /opt/suupr/Valeriy/PythonProject2/local.env
```

Добавить/обновить переменные:

```env
# VK Bot (НОВАЯ ГРУППА)
VK_BOT_TOKEN=vk1.a.XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
VK_GROUP_ID=123456789
```

## 6. Запуск VK-бота

```bash
# Перезапустить сервис
systemctl restart suupr-vk-bot

# Проверить статус
systemctl status suupr-vk-bot

# Посмотреть логи
journalctl -u suupr-vk-bot -f
```

## 7. Проверка работы

1. Написать в сообщения группы любое слово
2. Бот должен ответить приветственным сообщением / меню
3. Если не отвечает — проверить логи:
   ```bash
   journalctl -u suupr-vk-bot -n 50 --no-pager
   ```

## Устранение проблем

| Ошибка | Решение |
|--------|---------|
| `VK_BOT_TOKEN не найдена` | Проверить local.env, переменная не задана |
| `Ошибка 38 (Unknown application)` | Пересоздать токен с нужными правами, включить чат-бот в настройках группы |
| `Ошибка 15 (Access denied)` | Включить Long Poll API в настройках группы |
| Бот не отвечает | Проверить что включены «Сообщения сообщества» |

## Автоматический деплой

VK-бот автоматически перезапускается при деплое через:
- `python deploy/deploy.py deploy` — ручной деплой
- Push в `main` — GitHub Actions
- Условие: `VK_BOT_TOKEN` должен быть в `local.env`
