## 1. Страница «Филиалы» — [/admin/branches](http://186.246.10.51/admin/branches)

Коммит: [`c666a02`](https://github.com/som1one/PromoutersWeb/commit/c666a02).

> ⚠ **Внимание тестировщикам.** Удаление филиала каскадно сносит **все** связанные
> записи: маршруты (с точками, GPS, фото), выплаты, ставки оплаты, планы расходов,
> заявки мастера и их вложения. Пользователи филиала **не удаляются** — у них просто
> сбрасывается привязка к филиалу. Это поведение зафиксировано на уровне БД
> (`ON DELETE CASCADE` / `SET NULL`), и UI выводит соответствующее предупреждение
> и confirm-диалог. Не удаляйте «Москва Центр» / «Москва Север» во время тестов.

### 1.1. Доступ и навигация
- [ ] Войти как owner (`+79990000001`) на [/admin/login](http://186.246.10.51/admin/login)
- [ ] В сайдбаре в группе «Управление» виден пункт «🏢 Филиалы»
- [ ] Войти как `branch_manager` (`+79990000002`) → пункта **нет**
- [ ] Прямой переход [/admin/branches](http://186.246.10.51/admin/branches) под `branch_manager` → редирект на forbidden

### 1.2. Список филиалов
- [ ] Под owner: открыть [/admin/branches](http://186.246.10.51/admin/branches)
- [ ] Сверху страницы видна жёлтая плашка-предупреждение про каскадное удаление
- [ ] Видны строки «Москва Центр», «Москва Север» (из seed)
- [ ] У каждой строки есть кнопки «Изменить» и «Удалить»

### 1.3. Создание филиала
- [ ] Заполнить форму: Название = «Краснодар Центр», Город = «Краснодар»
      (autocomplete предлагает города из таблицы `cities`),
      Адрес, Код = `krd-center`
- [ ] Чекбокс «Активен» по умолчанию включён
- [ ] Нажать «Добавить» → редирект на список с зелёной плашкой «Филиал создан»
- [ ] Новый филиал виден в таблице

### 1.4. Редактирование
- [ ] Нажать «Изменить» рядом с «Краснодар Центр»
- [ ] Изменить название на «Краснодар Северный»
- [ ] Сохранить → плашка «Изменения сохранены»
- [ ] В таблице обновлённое название

### 1.5. Удаление пустого филиала
- [ ] Удалить «Краснодар Северный» (нет пользователей/маршрутов)
- [ ] В confirm-диалоге явно перечислены типы удаляемых записей
- [ ] После подтверждения → плашка «Филиал удалён», строка пропала

### 1.6. Каскадное удаление со связями (⚠ деструктивный кейс)
*Не выполняйте на «Москва Центр» / «Москва Север» — они нужны для других тестов.*
- [ ] Создать тестовый филиал «Тест-каскад»
- [ ] [/admin/users/register](http://186.246.10.51/admin/users/register) — создать тестового
      пользователя с ролью `promoter` в этом филиале
- [ ] [/admin/routes/create](http://186.246.10.51/admin/routes/create) — создать маршрут
      в «Тест-каскад» (минимум 2 точки)
- [ ] Вернуться на [/admin/branches](http://186.246.10.51/admin/branches), удалить «Тест-каскад»,
      подтвердить confirm
- [ ] Плашка «Филиал удалён»
- [ ] [/admin/routes](http://186.246.10.51/admin/routes) — маршрута больше нет (каскад)
- [ ] [/admin/users](http://186.246.10.51/admin/users) — тестовый пользователь **остался**
      в системе, но в колонке «Филиал» — пусто (привязка сброшена)
- [ ] [/admin/audit](http://186.246.10.51/admin/audit) — есть запись `branch.delete`

## 4. Маршрут промоутера: сохранение точек

URL: [/admin/routes/create](http://186.246.10.51/admin/routes/create), [/admin/routes](http://186.246.10.51/admin/routes).
Коммит: [`6af6a21`](https://github.com/som1one/PromoutersWeb/commit/6af6a21).

### 4.1. Создание с 4 точками (кейс Валерия)
- [ ] Войти как owner
- [ ] [/admin/routes/create](http://186.246.10.51/admin/routes/create), заполнить:
      Название = «Тест Краснодар 4 точки», Дата = сегодня+1, Филиал = любой
- [ ] На карте кликнуть в 4 разных места по Краснодару
- [ ] В списке точек: #1 = `start`, #2/#3 = `checkpoint`, #4 = `finish`
- [ ] Нажать «Создать маршрут»
- [ ] Редирект на `/admin/routes/{id}`, статус `draft`, «4 точек»

### 4.2. Редактирование точек
- [ ] На той же странице перетащить 2 маркера в новые места
- [ ] Удалить одну точку (× в списке) → остаётся 3 точки
- [ ] Сохранить → редирект, точки сохранены

### 4.3. Ошибка валидации не теряет введённые точки
- [ ] Создать новый маршрут, поставить **только 1** точку
- [ ] Нажать «Создать»
- [ ] Видна красная плашка «Маршрут должен содержать минимум 2 точки…»
- [ ] **Точка на карте остаётся** (не пропала после ошибки)
- [ ] Поставить вторую точку, сохранить → ОК
