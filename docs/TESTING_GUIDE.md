- `Центр: завершённый почасовой маршрут`

### Выплаты

- `Маршрут завершён`
- `Обновлены демо-данные`

## Быстрый сценарий проверки

### 1. Собственник

- Войдите под `+79990000001`
- Откройте `/app/admin/routes`
- Убедитесь, что видны 6 маршрутов из двух филиалов
- Откройте `/app/payouts` и проверьте 2 выплаты
- Откройте `/app/audit-logs` и убедитесь, что журнал доступен

### 2. Руководитель филиала `Москва Центр`

- Войдите под `+79990000002`
- В `/app/admin/routes` должны быть видны только маршруты центра
- В `/app/payouts` должны быть видны 2 выплаты центра
- В `/app/audit-logs` журнал доступен
- При попытке запросить аудит другого филиала backend возвращает `403`

### 3. Директор по рекламе

- Войдите под `+79990000003`
- Проверьте доступ к `/app/admin/routes`
- Откройте активный и завершённый маршруты
- Убедитесь, что фотоотчёты и статусы отображаются

### 4. Промоутер центра

- Войдите под `+79990000004`
- В `/app/routes` должны быть видны 4 маршрута, назначенные этому промоутеру
- Для `Центр: назначенная смена` доступен старт
- Для `Центр: активная смена` доступно продолжение и финиш
- В `/app/notifications` должны быть 2 уведомления
- В `/app/audit-logs` доступа быть не должно, ожидается `403`

### 5. Северный филиал

- Войдите под `+79990000005`
- Должен быть виден только `Север: маршрут другого филиала`
- Выплат быть не должно
- Журнал должен содержать только записи северного филиала

- Войдите под `+79990000006`
- Должен быть виден только один маршрут
- Доступа к журналу быть не должно

### 6. Мастер

- Войдите под `+79990000007`
- Логин должен проходить успешно
- `/app/routes`, `/app/payouts`, `/app/audit-logs` сейчас должны быть недоступны
- Можно использовать аккаунт как smoke-test на корректные ограничения ролей

## Проверенные факты по API

- `owner` видит `6` маршрутов, `2` выплаты, `1` уведомление
- `manager.center` видит `5` маршрутов, `2` выплаты, `1` уведомление
- `director.center` видит `5` маршрутов, `2` выплаты
- `promoter.center` видит `4` маршрута, `2` выплаты, `2` уведомления
- `manager.north` видит `1` маршрут и не видит чужой филиал
- `promoter.north` видит `1` маршрут и получает `403` на аудит
- `master.center` логинится, но получает `403` на маршруты, выплаты и аудит
