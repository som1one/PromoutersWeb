## Сценарий 1 — собственник

1. Открыть `http://72.56.38.35/admin/login`, войти под `owner.demo / demo12345`.
2. На главной видно сводку статусов заявок. Не должно быть 500 ни на одной странице.
3. **Пользователи** (`/admin/users`):
   - Открыть, увидеть список с фильтром по роли/филиалу.
   - Нажать «➕ Новый пользователь», создать тестового мастера.
   - Открыть его карточку, изменить роль на «Промоутер», сохранить.
   - Удалить созданного пользователя.
4. **Статистика** (`/admin/stats`):
   - Сменить период (Сегодня / Месяц / Год), убедиться что цифры пересчитываются.
   - Проверить, что показывается «ЗП мастеров по направлениям».
5. **Маршруты** (`/admin/routes`):
   - «➕ Новый маршрут» — заполнить, кликнуть по карте 3 точки, сохранить.
   - В созданном маршруте назначить промоутера, увидеть статус «assigned».
6. **План расходов** (`/admin/expense-plans`):
   - Открыть план в `submitted`, одобрить с комментарием.
   - Уведомление автору должно быть создано (см. /admin/notifications у автора).
7. **Выплаты** (`/admin/payouts`):
   - Одобрить выплату в статусе `calculated`, потом «Отметить выплачено».
   - Скачать `payouts.csv`.
8. **Уведомления**: бейдж в шапке, переход по ссылке.

## Сценарий 2 — руководитель филиала

1. Войти как `manager.center`.
2. Видит только свой филиал в `/admin/promoters`, `/admin/routes`, `/admin/payouts`.
3. Создать план расходов → «Отправить на согласование» → переходит в `submitted`.
4. Под owner — увидеть уведомление и одобрить.
5. Снова под manager — план в статусе `approved`.

## Сценарий 3 — мастер

1. Войти как `master.center`.
2. В `/admin/master-requests` видно только заявки, назначенные на него.
3. Открыть заявку в `new`, нажать «Принять» → статус `accepted`.
4. Перейти в `on_the_way` → должен появиться индикатор «GPS активен».
5. `in_progress` → `completed` → «Забрать на СД» (`handed_over`).
6. Прикрепить БСО (PDF/JPG) на статусе `completed`/`handed_over`.
7. Добавить комментарий — отображается в детальной странице.

## Сценарий 4 — диспетчер

1. Войти как `dispatcher.demo`.
2. Видит `/admin/orders`, может создавать новую заявку.
3. Видит `/admin/master-requests` своего филиала.

## Сценарий 5 — мобильный режим

Проверить на мобильном или в DevTools (375×812):

- Гамбургер-меню работает, drawer выезжает слева.
- Таблицы превращаются в карточки (стек), нет горизонтального скролла.
- Все кнопки/поля минимум 44×44px.
- Бейдж непрочитанных уведомлений виден в верхней панели.

## Регрессионный smoke (auto)

После каждого деплоя CI прогоняет:

- Логин под owner / branch_manager / master / dispatcher.
- GET для `/admin/`, `/admin/stats`, `/admin/users`, `/admin/promoters`, `/admin/routes`, `/admin/payouts`, `/admin/expense-plans`, `/admin/master-requests`, `/admin/notifications`, `/admin/audit`, `/admin/cash`.
- Любой 500 — красный билд.
