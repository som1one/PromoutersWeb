# UAT Checklist

## Авторизация

- Вход по телефону и паролю работает для всех demo ролей.
- При `AUTH_SMS_ENABLED=true` приходит challenge и проходит подтверждение кода.
- При `AUTH_SMS_ENABLED=false` вход завершается сразу.
- `refresh` обновляет access token без разрыва сессии.

## Роли и доступы

- Собственник видит все кабинеты управления, выплаты и журнал.
- Руководитель филиала не может смотреть audit другого филиала.
- Директор по рекламе видит управление маршрутами и отчёты своего контура.
- Промоутер не видит `admin/routes` и `audit-logs`.

## Маршруты и отчёты

- Создание, назначение и просмотр маршрута работают.
- Промоутер может стартовать и завершать маршрут.
- После завершения доступен отчёт с временем, GPS, фото и payout.
- В карточке completed маршрута отображается итоговый summary.

## Выплаты

- Для `hourly` рассчитывается сумма по времени.
- Для `per_leaflet` рассчитывается сумма по листовкам.
- В разделе выплат видны `amount`, `units`, `rate_type`, `calculation_details`.
- Руководитель видит группировку по промоутерам.

## Уведомления

- При назначении маршрута у промоутера создаётся уведомление.
- Напоминание по фотоотчёту создаётся при вызове dispatch endpoint.
- После завершения маршрута уведомление получает руководитель.
- Собственник видит ключевые системные изменения.

## Мобильный сценарий

- Промоутерский кабинет читается на ширине 390px.
- Нижняя навигация ведёт к маршрутам, выплатам, уведомлениям и профилю.
- Фотоотчёт и GPS сценарий не ломают layout на мобильном экране.
