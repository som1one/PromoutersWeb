# Система аутентификации веб-админки

## Обзор

Система аутентификации работает только через **логин и пароль**. Вход через VK ID удален.

## Базовый пароль для собственника

При первом запуске приложения автоматически создается базовый аккаунт собственника с параметрами из `.env`:

```env
OWNER_USERNAME=admin
OWNER_PASSWORD=admin123
```

Если эти переменные не указаны, используются значения по умолчанию:
- Логин: `admin`
- Пароль: `admin123`

**⚠️ ВАЖНО:** После первого входа смените пароль через интерфейс управления пользователями!

## Доступные роли для входа

Все следующие роли могут войти в веб-интерфейс:
- 👑 **owner** (Собственник) - полный доступ
- 👔 **director** (Директор) - доступ к статистике и управлению заявками своего города
- 📞 **dispatcher** (Диспетчер) - доступ к управлению заявками
- 🔧 **master** (Мастер) - ограниченный доступ

## Добавление паролей для пользователей

### Способ 1: Регистрация нового пользователя

1. Войдите как **owner**
2. Перейдите в раздел "👥 Управление пользователями"
3. Нажмите "➕ Создать пользователя"
4. Заполните форму:
   - **Логин** (обязательно, минимум 3 символа)
   - **Пароль** (обязательно, минимум 6 символов)
   - **Роль** (owner, director, dispatcher, master)
   - **Город** (обязательно для director)
   - **VK ID** (опционально)

### Способ 2: Установка пароля существующему пользователю

1. Войдите как **owner**
2. Перейдите в раздел "👥 Управление пользователями"
3. Найдите пользователя (⚠️ означает, что пароль не установлен)
4. Нажмите "✏️ Изменить"
5. Введите новый пароль в поле "Новый пароль"
6. Сохраните изменения

## Интерфейс управления пользователями

В таблице пользователей отображается:
- 🔐 - пароль установлен
- ⚠️ - пароль не установлен (пользователь не сможет войти)

При редактировании пользователя:
- Если пароль не установлен, отображается предупреждение
- Можно установить пароль, введя его в поле "Новый пароль"
- Минимум 6 символов

## Безопасность

- Пароли хранятся в виде хешей (bcrypt)
- Минимальная длина пароля: 6 символов
- Минимальная длина логина: 3 символа
- Логин должен быть уникальным

## Переменные окружения

Добавьте в `.env`:

```env
# Базовый пароль для owner (по умолчанию: admin/admin123)
OWNER_USERNAME=admin
OWNER_PASSWORD=admin123

# Порт веб-админки (по умолчанию: 8000)
ADMIN_PORT=8000

# Секретный ключ для сессий
ADMIN_SECRET_KEY=your-secret-key-here
```
