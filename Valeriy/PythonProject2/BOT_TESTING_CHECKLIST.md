## 📝 ЗАМЕТКИ ДЛЯ ТЕСТИРОВАНИЯ

### Роли для тестирования:
- **Owner**: Полный доступ ко всем функциям
- **Director**: Доступ к заявкам своего города, кассе, СД, статистике
- **Dispatcher**: Доступ только к созданию и назначению заявок
- **Master**: Доступ к своим заявкам, кассе, СД, отметке о смене
- **User**: Минимальный доступ (если используется)

### Тестовые данные:
- Создать тестовые заявки с разными статусами
- Создать мастеров в разных городах
- Создать заявки с чеками и без
- Создать заявки с разными суммами и типами техники

### Инструменты для тестирования:
- Логи бота (проверить логирование всех действий)
- База данных (проверить корректность записей)
- VK API (проверить отправку сообщений)
