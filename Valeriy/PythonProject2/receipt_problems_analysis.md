# Анализ проблем с чеками

## Возможные проблемы и их причины

### 1. **Проблема с сохранением файла в боте**

**Место:** `vk_bot.py`, функция `_save_receipt_locally()`

**Проблемы:**
- Если `_save_receipt_locally()` возвращает `None` (ошибка при скачивании/сохранении), но `receipt_file_id` уже сохранен в `state["data"]["receipt_file_id"]`, то:
  - `receipt_local_path` будет `None`
  - При сохранении заявки система попытается найти файл по паттерну, но его может не быть на диске
  - В БД сохранится только `receipt_file_id`, но не `receipt_file_path`

**Причины ошибок в `_save_receipt_locally()`:**
- Сетевые ошибки при скачивании файла с VK API (`requests.get()` может упасть)
- Таймаут при скачивании (30 секунд может быть недостаточно для больших файлов)
- Ошибки записи на диск (недостаточно прав, нет места на диске)
- Неправильный URL от VK API
- Отсутствие директории `bso_files` (хотя есть `mkdir(exist_ok=True)`, но могут быть проблемы с правами)

### 2. **Проблема с путями (абсолютные vs относительные)**

**Место:** `vk_bot.py` и `admin_fastapi.py`

**Проблемы:**
- В `vk_bot.py` сохраняется абсолютный путь: `str(file_path.resolve())`
- В Docker контейнере абсолютные пути могут быть разными на разных машинах
- Если контейнер перезапускается или файлы монтируются из другого места, пути могут стать невалидными
- В `admin_fastapi.py` есть логика для обработки относительных путей, но она может не сработать, если путь абсолютный, но файл не существует

**Пример проблемы:**
```python
# В боте сохраняется: /app/bso_files/receipt_123_1234567890.jpg
# Но в Docker файл может быть в: /data/bso_files/receipt_123_1234567890.jpg
# Или рабочая директория изменилась
```

### 3. **Проблема с синхронизацией receipt_file_id и receipt_file_path**

**Место:** `vk_bot.py`, функция `_payload_confirm_sum_input()`

**Проблемы:**
- Если `receipt_file_id` сохранен, но `receipt_local_path` = `None` (файл не был сохранен локально)
- Система пытается найти файл по паттерну `receipt_{order_id}_*`
- Но если файл не был сохранен из-за ошибки, его не будет на диске
- В БД останется только `receipt_file_id`, но без `receipt_file_path`
- В веб-интерфейсе система попытается найти файл по паттерну, но не найдет

### 4. **Проблема с поиском файлов по паттерну**

**Место:** `admin_fastapi.py`, функция `get_receipt_file()`

**Проблемы:**
- Поиск по паттерну `receipt_{order_id}_*` может найти не тот файл, если есть несколько файлов для одной заявки
- Если файл был сохранен с другим именем (не по паттерну), он не будет найден
- Поиск происходит только в `BSO_FILES_DIR`, но файл может быть в другом месте

### 5. **Проблема с обработкой разных типов вложений**

**Место:** `vk_bot.py`, функция `_save_receipt_locally()`

**Проблемы:**
- Обрабатываются только `photo` и `doc`
- Если пользователь отправил другой тип вложения (например, `video`, `audio`), функция вернет `None`
- Но `receipt_file_id` может быть сохранен, что создаст несоответствие

### 6. **Проблема с правами доступа**

**Место:** `vk_bot.py` и `admin_fastapi.py`

**Проблемы:**
- Если у процесса нет прав на создание директории `bso_files`, `mkdir(exist_ok=True)` может не сработать
- Если у процесса нет прав на запись файла, `open(file_path, "wb")` упадет
- В Docker контейнере могут быть проблемы с правами на монтированные volumes

### 7. **Проблема с обработкой ошибок**

**Место:** `vk_bot.py`, функция `_save_receipt_locally()`

**Проблемы:**
- Ошибки логируются, но не обрабатываются на уровне выше
- Если файл не был сохранен, но `receipt_file_id` уже в state, пользователь не узнает об ошибке
- При сохранении заявки нет проверки, что файл действительно существует на диске

### 8. **Проблема с обновлением пути в БД**

**Место:** `admin_fastapi.py`, функция `get_receipt_file()`

**Проблемы:**
- Если файл найден по паттерну, путь обновляется в БД: `order.receipt_file_path = str(receipt_path.resolve())`
- Но если файл был найден в альтернативной директории и скопирован, путь может быть неверным при следующем запросе
- Нет проверки, что обновленный путь действительно валидный

### 9. **Проблема с форматом имени файла**

**Место:** `vk_bot.py`, функция `_save_receipt_locally()`

**Проблемы:**
- Для фото всегда используется расширение `.jpg`, даже если это PNG или другой формат
- Для документов расширение берется из `title`, но если его нет, используется `.doc`
- Это может привести к проблемам при открытии файла

### 10. **Проблема с race condition**

**Место:** `vk_bot.py` и `admin_fastapi.py`

**Проблемы:**
- Если два процесса одновременно пытаются сохранить/получить файл для одной заявки, могут возникнуть проблемы
- При обновлении `receipt_file_path` в БД может быть race condition

## Рекомендации по исправлению

1. **Улучшить обработку ошибок в `_save_receipt_locally()`:**
   - Если файл не был сохранен, не сохранять `receipt_file_id` в state
   - Или сохранять, но логировать предупреждение и уведомлять пользователя

2. **Использовать относительные пути:**
   - Сохранять в БД относительный путь от `BSO_FILES_DIR`
   - При получении файла всегда использовать `BSO_FILES_DIR / relative_path`

3. **Добавить валидацию при сохранении заявки:**
   - Проверять, что если есть `receipt_file_id`, то должен быть и файл на диске
   - Если файла нет, пытаться скачать его из VK API по `receipt_file_id`

4. **Улучшить логирование:**
   - Логировать все этапы сохранения и получения файлов
   - Логировать ошибки с полным traceback

5. **Добавить fallback механизм:**
   - Если файл не найден на диске, но есть `receipt_file_id`, попытаться скачать его из VK API
   - Сохранить скачанный файл в правильное место

6. **Добавить проверку прав доступа:**
   - При старте приложения проверять, что есть права на создание/запись в `bso_files`
   - Если прав нет, логировать ошибку и уведомлять администратора

7. **Улучшить обработку разных типов файлов:**
   - Определять реальный тип файла по содержимому, а не по расширению
   - Сохранять правильное расширение

8. **Добавить мониторинг:**
   - Отслеживать количество заявок с `receipt_file_id`, но без `receipt_file_path`
   - Отслеживать количество заявок с `receipt_file_path`, но без файла на диске
