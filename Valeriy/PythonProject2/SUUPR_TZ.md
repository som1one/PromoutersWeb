# Техническое задание

## 1. Название проекта

Система управления доступом и учёта работы промоутеров (СУУПР)

## 2. Краткое описание

Веб-приложение для контроля работы промоутеров, учёта распространения рекламных материалов и финансового учёта.

Система предусматривает:

- многоуровневую систему прав доступа;
- геопозиционирование;
- автоматизированную отчётность.

Целевая аудитория:

- собственники бизнеса;
- руководители филиалов;
- директора по рекламе;
- мастера;
- промоутеры.

## 3. Цели и задачи

### Цель

Автоматизировать учёт работы промоутеров и контроль расходов в рекламной деятельности.

### Задачи

- реализовать многоуровневую систему авторизации и прав доступа;
- внедрить функционал геопозиционирования для отслеживания работы сотрудников;
- создать систему отчётности по распространению рекламных материалов;
- обеспечить финансовый учёт и формирование отчётности для выплат;
- организовать согласование расходов с собственником.

## 4. Роли пользователей и их права

### Собственник

- полный доступ ко всей базе данных;
- возможность назначать права доступа;
- просмотр всех отчётов и финансовых данных;
- получение уведомлений о любых изменениях, вносимых другими пользователями, особенно руководителем филиала.

### Руководитель филиала

- назначение ролей: «директор по рекламе», «мастер», «промоутер»;
- просмотр статистики: средний чек, оборот, зарплата мастеров по направлениям;
- составление плана расходов: аренда офиса, стоимость и количество материалов;
- отправка плана расходов на согласование собственнику.

### Директор по рекламе

- назначение промоутеров;
- приём отчётов от промоутеров;
- передача отчётов руководителю филиала;
- создание маршрутов и карт для промоутеров в виде фото или описания маршрута;
- установка типа оплаты для промоутеров: почасовая или за листовку, а также соответствующих ставок.

### Мастер

- принятие заявок и установка статусов: «принял», «в пути», «в работе», «готово», «забрал на СД»;
- автоматическое включение геопозиции при статусе «в пути»;
- автоматическое выключение геопозиции при статусе «готово»;
- прикрепление БСО к заявкам, которые забрал на СД;
- добавление комментариев к заявкам.

### Промоутер

- нажатие кнопки «Старт» при выходе на точку начала маршрута с активацией геопозиционирования;
- получение напоминаний о фотоотчёте с геопозицией каждые 15-30 минут в хаотичном порядке;
- предоставление отчёта по завершении маршрута: количество распространённых листовок, время выполнения, фотоотчёты с геопозицией.

## 5. Функциональные требования

### Авторизация и управление правами

- форма входа с полями «логин» и «пароль»;
- система ролей с настраиваемыми правами доступа;
- интерфейс для собственника по назначению и редактированию прав доступа.

### Геопозиционирование

- определение местоположения пользователя через GPS или интернет;
- автоматическое включение и выключение геопозиции в зависимости от статуса заявки для мастера;
- фиксация геопозиции при фотоотчётах для промоутера.

### Работа с заявками для мастера

- список заявок со статусами;
- изменение статуса заявки с автоматическим включением и выключением геопозиции;
- прикрепление БСО и добавление комментариев к заявке.

### Маршрутизация и отчётность для промоутера

- отображение назначенного маршрута или карты;
- кнопка «Старт» для начала работы на маршруте;
- автоматические напоминания о фотоотчёте;
- форма отчёта по завершении маршрута: количество листовок, время, фотоотчёты.

### Отчётность и финансы

- автоматический расчёт выплат для промоутеров на основе типа оплаты: почасовая или за листовку;
- формирование финансового отчёта с детализацией: имя промоутера, номер маршрута, количество листовок, сумма к выплате;
- интеграция с разделом «Доход/Расход» с гиперссылками на детализацию по каждому промоутеру.

### Уведомления

- уведомления собственнику о любых изменениях в системе, особенно о действиях руководителя филиала;
- уведомления о напоминаниях для промоутеров.
