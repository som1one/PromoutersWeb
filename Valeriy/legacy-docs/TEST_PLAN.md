---

## 1. Аутентификация и Авторизация

### 1.1 Страница входа (/auth/login)
- [ ] Открывается страница входа
- [ ] Введите неверный телефон/пароль → ошибка "Неверный номер телефона или пароль"
- [ ] Введите данные неактивного пользователя → ошибка "Пользователь деактивирован"
- [ ] Введите корректные данные → переход на /app
- [ ] Проверка редиректа: если уже авторизован → сразу на /app

### 1.2 Токены и сессия
- [ ] После входа токен сохраняется в localStorage
- [ ] При обновлении страницы сессия сохраняется
- [ ] После выхода токен удаляется
- [ ] С истекшим токеном → редирект на /auth/login

---

## 2. Роли пользователей

| Роль | Код | Доступ |
|------|-----|--------|
| Владелец | owner | Полный доступ |
| Менеджер филиала | branch_manager | Admin routes, audit logs |
| Рекламный директор | ad_director | Admin routes, audit logs |
| Промоутер | promoter | Только свои маршруты |

### 2.1 Проверка доступов
- [ ] Пользователь с ролью "promoter" НЕ видит "admin/routes"
- [ ] Пользователь с ролью "promoter" НЕ видит "audit-logs"
- [ ] Пользователь с ролью "owner" видит ВСЕ разделы
- [ ] Пользователь с ролью "branch_manager" видит admin-разделы

## 11. API Тестирование (через /docs)

### 11.1 Auth API
- [ ] POST /auth/login — вход
- [ ] POST /auth/refresh — обновление токена
- [ ] POST /auth/logout — выход

### 11.2 Routes API
- [ ] GET /routes — список маршрутов
- [ ] GET /routes/{id} — детали маршрута
- [ ] POST /routes — создание маршрута (admin)
- [ ] PUT /routes/{id} — обновление маршрута
- [ ] DELETE /routes/{id} — удаление маршрута

### 11.3 Users API
- [ ] GET /users — список пользователей (admin)
- [ ] GET /users/me — текущий пользователь
- [ ] PUT /users/me — обновление профиля

### 11.4 Finance API
- [ ] GET /finance/payouts — список выплат
- [ ] GET /finance/balance — баланс

### 11.5 Notifications API
- [ ] GET /notifications — список уведомлений
- [ ] PUT /notifications/{id}/read — отметить прочитанным

## 12. Негативные сценарии

### 12.1 Сетевые ошибки
- [ ] Отключить интернет → показывается ошибка соединения
- [ ] Вернуть интернет → приложение восстанавливается

### 12.2 Ошибки сервера
- [ ] 500 ошибка → понятное сообщение пользователю
- [ ] 404 ошибка → страница не найдена
- [ ] 403 ошибка → недостаточно прав

### 12.3 Валидация форм
- [ ] Пустые обязательные поля → ошибка
- [ ] Неверный формат телефона → ошибка
- [ ] Слишком длинный текст → ошибка
- [ ] Негативные числа в выплатах → ошибка
