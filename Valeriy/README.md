# Valeriy / архив старого проекта

Сюда вынесено всё, что **не участвует** в новой админке СУУПР. Код в этой папке
**не запускается** из текущего репозитория и не упоминается в активных
импортах. Хранится для истории и переноса данных.

## Состав

- `PythonProject2/` — старый монолит: VK-бот (`vk_bot.py`, `_vk/`, `vk/`),
  Telegram-бот (`telegram_bot.py`, `bot.py`, `handlers/`), серия legacy
  веб-админок (`admin_app.py`, `admin_fastapi.py`, `dispatcher_admin.py`,
  `master_admin.py`), их шаблоны (`templates/`), своя alembic-миграция,
  `model.py`, `db.py`, прочие одноразовые скрипты и `.md`-заметки.
- `legacy-docs/` — старые ТЗ и планы из корня:
  `DEVELOPMENT_PLAN_SUUPR.md`, `MVP_TZ_SUUPR.md`, `TEST_DATA.md`,
  `TEST_PLAN.md`, `README_TESTING.md`.
- `legacy-archives/` — архивы прошлых деплоев:
  `frontend_update.tar.gz`, `suupr_deploy.tar.gz`. В коммиты не попадают
  (исключены через `.gitignore`).
- `legacy-scripts/seed_pj2_data.py` — сидинг demo-данных под PJ2-таблицы;
  больше не вызывается из активного деплоя.

## Почему здесь, а не удалили

PJ2 содержит работающую логику ботов и старых админок, плюс данные миграции
`migrations/versions/0006_merge_pj2_tables.py` зависят от этой схемы. На
будущее код может пригодиться для повторного запуска ботов на отдельной
инфраструктуре. Локально в репозитории видеть его удобно как референс.

## Что **не** уезжает на GitHub

Папка `Valeriy/` целиком исключена из коммитов через `.gitignore`. Хранится
только локально. Если когда-нибудь понадобится отдельный репозиторий под
PJ2 — это уже отдельная история и отдельный remote.
